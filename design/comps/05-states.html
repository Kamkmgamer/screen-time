Paused by hand
The only state the user caused. The action sits where the reason does, so the fix is next to the problem.

The window in front is Tally
Past tense matters here. Saying "Tracking · Chrome" while Chrome is behind would be a lie.

Why a second line

“Idle” alone cannot separate a normal pause from a stop the user has to act on. Each state names its cause in one short sentence, using only what the tracker can actually stand behind.

What never changes

No spinner, no pulse, no colour. The dot is filled while seconds are landing and hollow while they are not. Pause and resume live in this block, not in the page header.

Counting Not counting The dot never pulses. Every state says what happens next, in the same two lines.
